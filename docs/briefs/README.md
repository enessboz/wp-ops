- Mevcut yazı biçimi: H2 yapısı, "at a glance" özet, tablo, SSS, "Sources and further reading", `sb-note` "Related" kutusu, güvenlik kuralı kutusu (gerekirse).

- Özgün görsel yoksa taslakta belirt.
